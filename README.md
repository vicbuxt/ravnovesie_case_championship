# Равновесие

Цифровой помощник врача и пациента для наблюдения за тревожно-депрессивной симптоматикой. Проект команды для кейс-чемпионата.

**Сайт:** https://vicbuxt.github.io/ravnovesie_case_championship/
**Модель оценки риска:** https://vicbuxt.github.io/ravnovesie_case_championship/risk_model_demo.html

## Как войти

1. Введите любой номер телефона и нажмите «Получить код».
2. Отправка SMS не подключена, поэтому код фиксированный:
   - **000** все роли (мастер-режим)
   - **111** врач-психотерапевт
   - **222** врач-психиатр
   - **333** пациент
   - **444** психотерапевт / психолог
   - **555** администратор

Кнопка «Выйти» не стирает данные. Можно сделать что-нибудь в кабинете пациента (запись в дневнике, запрос врачу, сообщение), выйти, войти как врач и увидеть, что запрос пришёл.

## Данные и конфиденциальность
- Всё, что вводит пользователь, хранится только в текущей вкладке браузера (`sessionStorage`). При закрытии вкладки данные удаляются.
- Сайт не отправляет данные на сервер и не обращается к сторонним сервисам. Шрифт и модель встроены в страницу.
- Пациенты в кабинете врача вымышленные, совпадения с реальными людьми случайны.

## Кабинет пациента
- **Дневник:** эмоции (с записью мыслей по схеме СМЭР) и сон.
- **Терапия:** цели и домашние задания, техники самопомощи с озвучкой.
- **Лечение:** препараты с отметкой приёма и опросники (PHQ-9, GAD-7, DASS-21).
- **Специалисты:** сообщения лечащему врачу и запись на приём.
- **Профиль:** анкета, документы, управление согласиями и выгрузка своих данных.
- **Кнопка SOS:** экстренные контакты и план безопасности.
- При входе пациент отдельно отмечает каждое согласие. Необязательные можно не давать и отозвать позже.

## Кабинет врача
- **Сегодня:** приёмы, пациенты, требующие внимания, контрольные точки плана.
- **Пациенты:** обзор, шкалы и дневники в динамике, препараты и проверка безопасности (противопоказания, лекарственные взаимодействия), план наблюдения, назначения, психотерапия, журнал решений.
- **Календарь приёма**, **Запросы** от пациентов, **Сообщения**.
- **Консилиумы** для решений по схеме лечения.
- **База препаратов** и внесение пациента из текста выписки.
- Кабинет настраивается: лишние разделы и виджеты можно скрыть.

Система подсказывает, а решения принимает врач. Ни одно назначение не меняется автоматически.

## Модель оценки риска
Тексты пациента (дневник, сообщения) проверяются на признаки суицидального риска. При высоком риске врач получает срочное уведомление, а пациенту показывается помощь.

- Ансамбль из 3 небольших трансформеров: 2 слоя, 4 головы внимания, размерность 64.
- Три класса: нет риска / умеренный / высокий. Пороги: высокий ≥ 0,50, умеренный ≥ 0,47. Пороги смещены в сторону чувствительности: ложное срабатывание разбирает врач, пропуск опаснее.
- Токены кодируются хешированием, длинные тексты разбиваются на фрагменты по 64 токена, итог считается по самому тревожному фрагменту.
- Веса квантованы и встроены в страницу. Модель работает целиком в браузере, текст никуда не отправляется.
- Анализ включается только при согласии пациента на автоматический анализ текста.
