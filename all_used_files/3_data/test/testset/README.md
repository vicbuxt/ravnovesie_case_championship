# Синтетический тестовый набор «Равновесие»

Набор для проверки прототипа цифрового помощника врача: детектора риска в дневнике, разбора выписок и правил по Авиандру и маршрутизации. Все данные **полностью вымышленные**: совпадения с реальными людьми случайны. Персональных данных нет.

## Состав

| Файл | Что внутри | Объём |
|---|---|---|
| `data/patients.csv` | Профили пациентов: диагноз, шкалы в динамике, препараты, противопоказания, анамнез — и **эталонные ответы системы** (колонки `exp_*`) | 60 |
| `data/diary_entries.csv` | Записи дневника эмоций (СМЭР и свободный текст) с **эталонной разметкой риска** | 436 |
| `data/discharge_notes.csv` | Выписки и направления 5 стилей с **эталонными извлечёнными полями** (колонки `gt_*`) | 30 |
| `data/notes_txt/` | Те же выписки отдельными текстовыми файлами | 30 |
| `testset_ravnovesie.xlsx` | Всё то же в одной таблице для просмотра + сводка | — |
| `evaluate_prototype.js` | Скрипт: прогоняет прототип на наборе и считает метрики | — |
| `results/` | Результаты прогона текущей версии прототипа | — |

Файлы CSV — в кодировке UTF-8 с BOM, разделитель — запятая, поэтому они корректно открываются в Excel. Записи связаны между собой через `patient_id`.

## 1. Дневник: правила разметки риска

Метка `risk_label` ставится по смыслу всей записи и только для **риска самого пациента**.

| Метка | Когда ставится | Примеры |
|---|---|---|
| **высокий** | Актуальные (не в прошлом) мысли о смерти, суициде или самоповреждении о себе — прямые или косвенные; самоповреждение; прощальное поведение; актуальные мысли на фоне прошлой попытки | «Не хочу больше жить», «Хочу уснуть и не проснуться», «Раздала вещи, они мне больше не понадобятся», «не хачу жить» |
| **безнадёжность** | Безнадёжность, никчёмность, ощущение себя обузой, пустота — **без** упоминания смерти | «Ничего уже не изменится», «Я обуза для близких», «Всё тлен» |
| **нет** | Обычные переживания; а также ловушки: идиомы и гиперболы, отрицание, речь о другом человеке, фильмы и учёба, мысли только в прошлом, ирония | «Умираю от скуки», «Мыслей о смерти нет», «Подруга написала, что не хочет жить» |

Принцип при сомнении: **выбирается более высокий уровень**. Это следует из требования минимизировать ложноотрицательные ответы. Поэтому «Не могу больше так жить» и «Хочется всё прекратить» размечены как «высокий».

Речь о другом человеке («подруга не хочет жить») размечена как «нет» для риска пациента. Клинически это важно, но это другой сигнал, и в продукте его стоит обрабатывать отдельно.

Колонка `trap_type` показывает тип сложности записи:

| Тип | Что это |
|---|---|
| `нет` | обычная запись |
| `indirect` | косвенная формулировка |
| `slang` | сленг |
| `typo` | опечатка |
| `past` | прошлое |
| `idiom` | идиома |
| `negation` | отрицание |
| `third_party` | о другом человеке |
| `media` | фильм, статья, учёба |
| `sarcasm` | ирония |

`difficulty` — уровень сложности: лёгкий или трудный. `rationale` — причина метки.

Записи с высоким риском сформулированы на уровне мыслей и намерений, без описания способов.

## 2. Пациенты: правила эталонных ответов

**Авиандр** (по листку-вкладышу ГРЛС и общей характеристике препарата):
- **Показания:** генерализованное тревожное расстройство (F41.1); тревожные состояния после COVID-19 со стрессовой реакцией и нарушением адаптации (F43.x + U09.9).
- **Противопоказания:**
  - гиперчувствительность к маритупирдину;
  - возраст до 18 лет;
  - беременность и грудное вскармливание;
  - эпилепсия и органические заболевания мозга;
  - печёночная недостаточность класса A–C по Чайлд-Пью;
  - СКФ ниже 60 мл/мин;
  - ингибиторы МАО сейчас или в последние 2 недели.
- **С осторожностью:**
  - сердечно-сосудистые заболевания;
  - сахарный диабет и эндокринные заболевания;
  - алкогольная или наркотическая зависимость;
  - пожилой возраст (65+);
  - непереносимость лактозы;
  - вождение (предупреждение о головокружении и сонливости).
- **Взаимодействия:**
  - ингибиторы МАО — противопоказано;
  - средства с этанолом, например Корвалол, — избегать;
  - серотонинергические препараты (СИОЗС, ТЦА, литий, зверобой, триптаны, трамадол) — с осторожностью;
  - седативные (бензодиазепины, нейролептики, снотворные, H1-блокаторы) — с осторожностью;
  - ингибиторы CYP2D6 (флуоксетин, пароксетин, дифенгидрамин, тербинафин, гидроксихлорохин) — с осторожностью.

**Итоговое решение** `exp_aviandr_decision` определяется по порядку:
1. есть противопоказание → «противопоказан»;
2. иначе нет показания → «вне зарегистрированных показаний»;
3. иначе есть осторожности или взаимодействия → «возможен по инструкции, с осторожностью»;
4. иначе → «возможен по инструкции».

**Врачебная комиссия** `exp_vk_required_5plus_meds`: «да», если с Авиандром получается 5 и более препаратов в сутки (приказ Минздрава № 1094н, п. 32).

**Направление к психиатру** `exp_psychiatrist_referral` — правила команды:
- **обязательно:** PHQ-9 п. 9 ≥ 1; PHQ-9 ≥ 20; высокий риск в дневнике; БАР у пациента или кровных родственников; суицидальная попытка в анамнезе;
- **желательно:** PHQ-9 15–19; GAD-7 ≥ 15; недостаточный ответ на терапию; беременность; безнадёжность в дневнике;
- иначе — «не требуется».

**Ответ на терапию** `exp_treatment_response` считается после 4 и более недель терапии по основной шкале. Для F41.1 и F43 это GAD-7, для депрессии — PHQ-9.
- снижение на 50% и больше — ответ;
- 25–49% — частичный ответ;
- меньше 25% — недостаточный.

**Тяжесть:**
- PHQ-9: 0–4 минимальная, 5–9 лёгкая, 10–14 умеренная, 15–19 умеренно тяжёлая, 20+ тяжёлая;
- GAD-7: 0–4, 5–9, 10–14, 15+.

**Типы профилей** (`archetype`):

| Тип | Сколько | Что это |
|---|---|---|
| `gtr_ok` | 10 | ГТР без препятствий |
| `gtr_caution` | 8 | ГТР с осторожностями |
| `gtr_contra` | 10 | ГТР с противопоказаниями: беременность ×2, лактация, эпилепсия, печень, СКФ ×2, МАО, 17 лет, аллергия |
| `gtr_inter` | 7 | ГТР с взаимодействиями |
| `covid` | 5 | тревога после COVID-19 |
| `dep_mild` | 8 | лёгкая и средняя депрессия |
| `dep_severe` | 5 | тяжёлая депрессия |
| `mixed` | 3 | смешанное тревожно-депрессивное расстройство |
| `bip_risk` | 4 | БАР в семье или суицидальная попытка в анамнезе |

## 3. Выписки: эталонные поля

Стили:
- структурированная выписка;
- свободный текст;
- сокращения («Д-з», «Б-ть», «Алк.»);
- выписной эпикриз;
- направление.

Препараты встречаются и под торговыми названиями: Золофт, Донормил, Ламизил, Пиразидол, Негрустин. В эталоне они приведены к МНН.

Есть отрицания («Эпилепсию, ЧМТ отрицает», «Беременность отрицает»), лабораторные данные (креатинин, СКФ) и сопутствующие диагнозы с кодами МКБ-10.

`не указано` в эталоне означает, что в тексте нет сведений, `не применимо` — поле не относится к пациенту (беременность у мужчин).

## 4. Как прогнать прототип

Нужен Node.js.

```
npm install jsdom
node evaluate_prototype.js ravnovesie_prototype.html data results
```

Скрипт загружает прототип и прогоняет его функции:
- детектор `analyze` — на каждой записи дневника;
- разбор выписок `runExtract` — на каждой выписке;
- правила `aviCheck` и `routing` — на каждом профиле.

Сводка записывается в `results/results.md` и `results/results.json`, все ошибки — в `results/*_errors.csv`.

| Компонент | Метрика | Значение |
|---|---|---|
| Детектор риска | Чувствительность к высокому риску | **27,4%** (17 из 62) |
| | Хоть какой-то сигнал при высоком риске | 33,9% |
| | Ложные тревоги на записях без риска | 5,1% |
| | Сленг / опечатки / косвенные формулировки | 0% / 0% / 12% |

| | Список препаратов полностью | 86,7% |
| | Беременность / пол / возраст / эпилепсия | 70% / 70% / 60% / 63% |
| Правила | Решение по Авиандру | 98,3% (59 из 60) |
| | Направление к психиатру | 100% |
| | Врачебная комиссия при 5+ препаратах | 100% |

**Что это значит.** Детектор в прототипе — заглушка на словаре из ~20 фраз, и набор это наглядно показывает. Требование «минимум ложноотрицательных» он не выполняет: нужна обученная модель и расширенный словарь как страховка.

Найденные ошибки разбора выписок:
- «напряжение» содержит «жен», поэтому пол мужчины определяется как женский;
- «Эпилепсию отрицает» считается эпилепсией;
- «Беременность: нет» считается беременностью;
- не распознаются возраст в форме «31 л.» и «возраст 35» и препарат «фолиевая кислота» из двух слов.

В правилах прототип не проверяет аллергию на сам препарат (P028).

Правила и эталон построены на одной логике (инструкция + правила команды), поэтому высокое совпадение здесь ожидаемо. Набор ловит ошибки реализации, а не спорные клинические решения.

## Ограничения

- Тексты и разметка созданы по явным правилам выше. Это не реальные записи пациентов, и клинической валидации экспертом разметка не проходила.
- Реальный язык пациентов разнообразнее: на реальных данных метрики будут ниже.
- Пороги маршрутизации — правила команды, а не клинические рекомендации. Если правила изменятся, пересчитайте эталон.
